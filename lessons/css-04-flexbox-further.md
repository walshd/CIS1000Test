# Flexbox Further Learning

Once you have finished this first part of todays tutorial please move on to the second compulsory tutorial. [https://teaching.computing.edgehill.ac.uk/wte/parts/9970](https://teaching.computing.edgehill.ac.uk/wte/parts/9970)

If you finish all of the tutorials early in class or wish to do some extra work for homework and improve your learning you can undertake the following:

- Open up VSCode and create yourself a basic image gallery and try using Flexbox to control it. Chat your work over with your tutor in your next seminar session if you have a go.

- Also, Mozilla have a tutorial on flex that can be found at: [https://developer.mozilla.org/en-US/docs/Learn/CSS/CSS_layout/Flexbox](https://developer.mozilla.org/en-US/docs/Learn/CSS/CSS_layout/Flexbox). They also have a testbed environment where you can test out your flexbox knowledge: [https://developer.mozilla.org/en-US/docs/Learn/CSS/CSS_layout/Flexbox_skills](https://developer.mozilla.org/en-US/docs/Learn/CSS/CSS_layout/Flexbox_skills)

## A slighly more fun way to learn and improve your Flexbox knowledge
